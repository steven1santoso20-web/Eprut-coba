# LATIHAN HTML

## Pembuatan Tabel

### Layout
- Menggunakan layout kotak.
- Terbagi menjadi 4 Tingkatan.
- Tampilan per kolom diisi dengan warna:
    * Header - Coklat Muda.
    * Navigasi - Biru Muda.
    * Heading 1 - Merah Muda.
    * Menu - Hijau Muda.
    * Footer - Coklat Muda.
### List
- Untuk tingkat pertama berisi Header.
- Untuk tingkat kedua berisi Navigasi.
- Untuk tingkat ketiga terbagi menjadi dua.
    * Heading 1.
    * Menu.
- Untuk tingkat keempat berisi Footer.
### Semantic Tag
- Untuk Heading 1 menggunakan font ukuran 30px dan Bolt.
- Untuk Header, Navigasi, dan Footer menggunakan font ukuran 10px.
- Untuk Menu menggunakan font ukuran 7px dan Bolt.
- Untuk dekripsi Heading 1 dan menu menggunakan 5px
